# runtime 使用说明（广石化实验室安全考试 · 脚本化做题）

一个纯 HTTP 的小工具：**离线缓存题库 + 自动做题**。不依赖浏览器、不需要人工点页面，只用 Python 标准库。

> 本目录可以直接打包带走（脚本里没有任何硬编码路径，全部用相对路径）。

---

## 1. 目录内容

| 文件 | 作用 |
|---|---|
| `gylabs_exam.py` | 主脚本，四个子命令：`list` / `login` / `bank` / `exam` |
| `bank.json` | 题库缓存。**随包发布的是空壳**，跑一次 `bank` 就会填满（并发模式下只要十几秒） |
| `cookie.txt.example` | Cookie 模板；复制成 `cookie.txt` 再填自己的 `JSESSIONID`（`cookie.txt` 不要外传） |
| `selftest/parse_check.py` | 离线自检：不联网、不用账号，验证解析器没被改坏（**发布前建议先跑它**） |
| `selftest/fixtures/*.html` | 自检用的**合成样本**（假考试/假题号/假题目，不含任何真实数据） |
| `gylabs-脚本化做题方案.md` | 原理、接口清单、踩坑记录（想二次开发看它） |

> `selftest` 是给这个工具自己用的“单元测试”：解析页面靠的是一堆正则，改代码或换环境后容易悄悄失效。
> 它只是把三个页面样本喂给解析器，断言解析结果对不对。样本是**手写的合成数据**，所以可以随包发布。

## 2. 环境要求

* Python 3.8+（实测 3.14），**不需要 pip 安装任何东西**。
* 能访问 `https://gylabs.gdupt.edu.cn`（校园网 / VPN）。
* Windows 下命令示例用 PowerShell，`cd` 到本目录再执行。

先跑一次离线自检确认环境没问题：

```powershell
cd <本目录>
python selftest\parse_check.py
```

看到 `结果：PASS —— 解析器工作正常` 就 OK（它不联网）。

## 3. 第一步：准备 Cookie

所有联网命令都需要一个**有效的登录会话**。三选一：

**方式 A（最稳，推荐）** 浏览器里登录 → F12 → **Application / 应用** → 左侧 Cookies → 点 `https://gylabs.gdupt.edu.cn` → 复制 `JSESSIONID` 的值 → 写进 `cookie.txt`：

（先 `copy cookie.txt.example cookie.txt` 生成这个文件）

```
JSESSIONID=你复制到的值
```

（`#` 开头的行会被当注释忽略；脚本每次跑完会把最新值写回这个文件。）

**方式 B** 不写文件，直接命令行传：

```powershell
python gylabs_exam.py list --cookie "JSESSIONID=你复制到的值"
```

**方式 C** 让脚本自己登录（需要人眼看验证码，且该站是两步登录，偶尔要重试）：

```powershell
python gylabs_exam.py login --user 你的学号 --password '你的密码' --cookie-jar cookie.txt
```
它会把验证码存成 `captcha.jpg`，打开看清 4 位数字后输入即可。

> ⚠️ 会话十几分钟不动就会失效。脚本开跑前会先做一次“是否已登录”体检，失效会直接报错，不会空转。

## 4. 第二步：看有哪些考试 / 拿 id

```powershell
python gylabs_exam.py list --cookie-jar cookie.txt
```

输出每场考试的 **exameid + 名称**，例如：

```
  16385289  外国语学院语言实验室安全准入考试（学生版）
  16770044  外国语学院语言实验室安全准入自测（不限次，用来刷题库）
```

* **考试 id**：上面这个列表里直接拿。
* **自测 id**：网页版点顶部「自测」→ F12 搜 `gotoTest('` → 引号里的数字就是（外国语学院自测 = `16770044`）。
* 常见 id 也内置在脚本里，`list` 输出末尾会一并打印。

## 5. 第三步：刷题库（自测不限次，随便刷）

```powershell
python gylabs_exam.py bank --cookie-jar cookie.txt --self-test 16770044 --runs 5 --bank bank.json
```

* 每轮流程：进自测 → 逐页收集 100 道题的题干图片 md5 → 交白卷 → 打开该次“整卷回顾页” → 按题号对齐成 `md5 → 正确答案`。
* **默认并发抓取**（`--jobs 6`，6 线程）。这 100 个翻页请求互相独立——同一场次里带上第 1 页的表单隐藏域、只改 `pageNum`，就可以直接取第 N 页，所以能并发：
  ```
  自测第 1/5 轮（每轮 100 页）
      采集完成：并发模式(6 线程)，100/100 页，用时 6.3s
      自测 52902274：回顾 100 题，新增 29 题，累计 129 题
  ```
  **实测一轮 100 页 / 6 线程 ≈ 41 秒**（同一网络下顺序模式一般要 1~3 分钟）。
  想再压时间就 `--jobs 8~16` 试；若提升有限，说明服务端按会话串行处理，那就只能接受这个速度（一轮几十秒、刷 3~5 轮，总共两三分钟）。
* 任何一页没抓到会自动单页重试；缺得多就**自动退回顺序模式**（相当于旧版行为，保证能跑通）。
  想强制用顺序模式（最稳最慢）：`--jobs 1`。
* 若日志里反复出现 `SSL: UNEXPECTED_EOF_WHILE_READING` / `The read operation timed out`，
  说明并发把服务端/中间设备惹毛了：**把并发降下来**（`--jobs 2~3`）或**放慢节奏**（`--pace 0.3`）。
  脚本已内置：请求最小间隔 0.12s、失败退避重试、三遍降级（并发 → 串行 → 加重试），个别页始终拿不到就跳过并继续，不会整轮白跑。
* 每轮结束就落盘，中途断了也不丢进度；下一轮会自动增量补齐。
* 跑到“新增 0 题”基本就满了（这套卷约 150 题）。随包发布的 `bank.json` 是**空的**，第一轮就能收进大部分；
  想要现成的题库缓存，自己刷完那份 `bank.json` 就是（它只含题目图片哈希+答案，不含个人信息，但仍属于考试内容，是否分享自己把握）。
* 判断题没法用“选项文本”区分，只能靠题干图片 md5 命中，所以判断题覆盖面取决于刷了多少轮——**多刷两轮更保险**。
* 可选：顺手抓“院系题库浏览页”的答案（快，但**不等于考试卷的题池**，只能算补充）：
  ```powershell
  python gylabs_exam.py bank --cookie-jar cookie.txt --dept 447555 --bank bank.json
  ```

## 6. 第四步：做题

**先演练（不交卷，不消耗机会）**：

```powershell
python gylabs_exam.py exam --cookie-jar cookie.txt --bank bank.json --exam 16385289 --dry-run
```

看输出里每题是 `md5` 命中还是 `sig`（选项文本）命中，以及有没有 `题库里没有，跳过`：

```
  第  1页 单选题 md5=46496284 -> B
  第  2页 多选题 md5=96a297ae -> A,B,C,D
  第 85页 判断题 md5=unknown  -> 题库里没有，跳过（需人工）
```

跳过太多就先回去多刷几轮题库。

**正式交卷**：

```powershell
python gylabs_exam.py exam --cookie-jar cookie.txt --bank bank.json --exam 16385289
```

跑完会打印成绩。要点：

* 该考试 **90 分钟 / 20 次机会 / 取最高分 / 95 分及格**（自测不限次）。
* 脚本会先保存末页再交卷（末页直接交卷历史上会丢答案，已规避）。
* 一次正式交卷 = 用掉一次机会，但取最高分，所以失误不会毁掉已有的好成绩。

## 8. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 一开始就报「Cookie 无效或已过期」 | 重新登录后抄一份新的 `JSESSIONID`（会话十几分钟就过期）。 |
| 刷题库很久没输出 | 正常情况下每 10 页会打点；**完全没有输出**说明卡在请求重试，多半 Cookie 失效。 |
| `进入自测失败（没拿到试卷页）` | Cookie 失效，或该账号没有这场自测的权限。 |
| 报「您不在允许考试的考生范围内」 | **服务端白名单问题，不是脚本问题**：这场考试按它的考生范围/名单不放行你这个账号（常见于你已经通过该考试之后，或它只对某些院系开放）。用 `list` 看它是否还在你可参加的列表里，找任课/实验室老师确认范围。自测不受影响。 |
| 报「进不去这场考试，服务端返回的不是试卷页」 | 就是上一条的高级版：脚本把服务端原话打出来了，按那句话处理。 |
| 提示「题库里没有，跳过」很多 | 题库没刷够，多跑 `bank --runs 3`；判断题尤其要多刷。 |
| `login` 子命令验证码老报错 | 该站是两步登录（`/logined.jsp` → `/j_spring_security_check`），验证码要尽快输入；嫌麻烦就用**方式 A 抄 Cookie**。 |
| 站点偶发连接被重置 | 重试即可；脚本内建 2~3 次重试。 |
| `bank.json` 被写坏/变成空的 | 写入已经是**原子替换**（先写 `.tmp` 再 rename），读坏文件会明确报错而不是静默清空；万一真没了，删掉重刷即可（`bank --runs 3`）。如果看到 `temp-AXM/` 这类目录，是外部工具搬走的副本，里面有备份的 `bank.json`。 |
| 觉得刷库还是慢 | 加大 `--jobs`（如 8~12），或减少 `--runs`；题库到“新增 0 题”就满了。 |

## 9. 原理（为什么这么做）

1. **题干是图片**：`\upload\theme_picture\<md5>.jpeg`，md5 是内容文件名，跨场次稳定 → 拿它当题库主键最可靠。
2. **选项每次打乱**：所以答案按**选项文本**存（`bank.json` 的 `by_sig`），答题时再映射成当前页的字母。
3. **自测不限次**：交卷后能打开“整卷回顾页”，里面有题干**文本**、选项、参考答案 → 与当次逐页的 md5 按题号对齐，等于免费给题库打标。
4. **95 分及格**：容错很小，所以判断题这种“只能按 md5 命中”的题型要多刷几轮补全。

更细的接口清单（每个 URL、参数、页面结构）见 `gylabs-脚本化做题方案.md`。

## 10. 注意

* `cookie.txt` 等同于你的登录凭证，**不要外传、不要放进公开仓库**。
* 只用你自己的账号做自己的考试；把题库缓存留着复用是省事，但别拿去传播账号。

## 11. 发布前检查清单（打算把本目录发给别人时）

1. `cookie.txt` **不能有**（只留 `cookie.txt.example`）。它等同登录凭证。
2. `bank.json` 建议保持空壳（随包就是空的）。想连题库一起发，自己确认愿意公开这份答案缓存。
3. 跑一遍离线自检：`python selftest\parse_check.py`，看到 `结果：PASS` 再发。
4. 扫一眼有没有自己的痕迹（把方括号换成你自己的学号/姓名，**期望结果为空**）：

   ```powershell
   Get-ChildItem -Recurse -File | Select-String -Pattern "[你的学号]", "[你的姓名]"
   ```

   顺带确认没有真实会话 id 残留：搜 `JSESSIONID=`，只应出现在 `cookie.txt.example` 和文档示例里（值是占位符 `xxxx`）。
5. 别把 `__pycache__/`、`*.pyc` 一起打包（运行后会生成，删掉即可）。
6. 只打包本目录的这 9 个文件；**别把子目录整包带走**（例如某些工具会生成 `AXM-runtime/`、`temp-AXM/` 之类的副本，
   里面可能带着 `cookie.txt`）。如果改过代码又是在副本里跑，记得把新脚本复制进副本。
